# 🚀 S HTML Minifier

**S HTML Minifier** is a fast, lightweight, zero-database online tool designed to compress and optimize HTML code instantly. It removes unnecessary white spaces, new lines, and HTML comments to reduce file size and improve web page load speed.

---

## 🌟 Features

* **Instant Minification:** Removes extra spaces, tabs, new lines, and comments using Regex logic.
* **One-Click Copy:** Easily copy the minified output directly to your clipboard.
* **Lightweight & Fast:** Runs 100% on the client-side browser with pure Vanilla JavaScript.
* **Zero Database:** Fully secure and privacy-focused.

---

## 🛠️ How to Use

1. **Open the Tool:** Visit [S HTML Minifier](www.sminifire.duckdns.org).
2. **Paste Code:** Copy your raw HTML code and paste it into the **Input** text area.
3. **Click Minify:** Press the **`Minify Now ⚡`** button.
4. **Copy Output:** Your clean, compressed HTML code will appear in the **Output** box. Click **`📋 Copy Code`** to copy it instantly!

---
